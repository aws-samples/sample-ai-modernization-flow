## 実行方針

- **リポジトリ間は並列**（同時実行数の上限: <N>本。**既定 5**。多コア機なら5程度まで実用的）
- **分析はリポジトリごとに1本**（CCA）。ATX は対象で `git checkout -b` するため、
  同一 git work tree での並列実行は不可（1本なのでこの制約は自動的に満たされる）
- **失敗は隔離する。** 1本の失敗が他を止めない。失敗分だけ再実行する
